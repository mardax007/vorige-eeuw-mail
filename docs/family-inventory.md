## Also find out

- **Solcon:** which package (GO holds 2 GB, Lite 5 GB) and the mailbox name shown in Mijn Solcon.
  The mailbox name is not always the address.
- **KPN addresses** (kpnmail, planet, hetnet, xs4all): KPN is moving mailboxes to "KPN Mail en Cloud"

- **Gmail users who read other mail inside Gmail:** Gmail is ending that feature.
- **Outlook:** which version, and whether the account is POP (mail in a `.pst` file) or IMAP (mail
  in an `.ost` file, still on the server). Outlook shows it under File, Account settings.
- **A copy of the old mail file** for the spike's PST probe, on Martijn's PC, outside this folder.
- **USB sticks** to move old mail: FAT32 sticks cannot hold a file of 4 GB or more.

## What each column decides

- **Provider:** which sign-in paths get built (password only, Google, Microsoft).
- **Mail program and where the mail lives:** which import readers get built. A `.pst` file means the
  PST reader. Mail still on a server means the mailbox route. The new Outlook app can export a `.pst`
  file. The Windows 10/11 Mail app (retired) keeps no importable files; Vista's older Windows Mail
  can be imported like Windows Live Mail.
- **How much:** whether it fits in the new mailbox, and whether imports must resume over days.
- **Windows version and Smart App Control:** Smart App Control must be off for an unsigned app.
  Find it in Windows Security, under App & browser control. Windows 10 does not have it. Windows 7
  and 8 cannot run the app at all.
- **Antivirus:** some scan mail connections; the spike checks that the app works behind them.
- **Phone:** whether the Android step is needed at all. iPhones cannot take an APK.
