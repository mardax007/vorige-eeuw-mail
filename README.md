# Vorige Eeuw Mail

A free mail app for the family: a Windows desktop app first, an Android app later. It opens the
mailboxes people already have and can bring in old mail from Outlook and Windows Live Mail.

This folder is set up for Claude Code to build the app phase by phase. There is no code yet.

## Where things are

| File | What it is |
| --- | --- |
| `CLAUDE.md` | Instructions Claude Code reads every session: rules, stack, how to work |
| `docs/PLAN.md` | The design and the facts behind it |
| `docs/DECISIONS.md` | What is decided, what is open, what is proposed |
| `docs/PROGRESS.md` | Where the build stands; updated every session |
| `docs/phases/` | One file per build step, with tasks and exit criteria |
| `docs/errors.md` | The error rule and the `VEM-…` code scheme |
| `docs/family-inventory.md` | To fill in: what each family member uses today |
| `docs/features.md` | What version 1 does, candidate features, what stays out |
| `docs/screens.md` | Screen rules for older, non-technical users |
| `docs/sync.md` | How the local mail cache stays correct |
| `docs/research.md` | The research pass of 16 November 2026: what changed and why, with sources |
| `docs/sources.md` | The pages the original plan relied on (newer ones are in `research.md`) |

## Getting started

1. Fill in `docs/family-inventory.md`. It decides most of the scope.
2. Answer the "before phase 1" questions in `docs/DECISIONS.md`.
3. Open this folder in Claude Code and say: "Read CLAUDE.md and start phase 1."
